# XXD Panel 047｜厚涂色域轴测微景观生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

### 模型优先级与凭据

- **优先使用 GPT Image 2。** 当 GPT Image 2 通过当前内置图像工具或已配置兼容通道可用时，先用它完成本提示词要求的高保真垫图／编辑与完整画布生成。

- 备用模型只替换生图通道，不得改变本提示词的模式、画幅、原图可见性、文案、语言、壁纸关系或“完整画布优先、拼合仅兜底”的执行逻辑。不能满足硬性条件时不得静默降级。
- 没有合适通道时，请用户启用生图工具或提供 API Key。用户主动提供凭据可以用于当前任务，但不得在回复、日志或提示词中回显、展示、记录或泄露其值；未经明确要求不得长期保存或修改全局路由配置。
- 按实际生图能力判断可用性，不因某个工具、供应商名称或单一环境变量缺失就武断判定全部通道不可用。

只处理当前新任务明确提供的这一张源照片。私下锁定身份、结构、姿态、方向、动作、功能、开口、关系、情绪含义与源图色彩，至少保留三个源图专属线索；不得借用其他输入、旧输出或样张。

## 审美重构

把可识别主体重构为精致立体的等距微缩实体，让它真实站立、生长、落地、倒影或穿越于源图衍生厚涂主题色域中；刮刀厚颜料成为水面、地面、道路、草地、光带、岸线或影子，而不是矩形背景。

严格遵循这条因果链：锁定身份、体积、朝向与落点 → 保留三个线索 → 重构一个精致等距微缩实体 → 从源图内容提炼一个主题空间切片 → 让厚涂成为水面、地面、道路、草地、光带、岸线或影子 → 建立真实落地、嵌入、穿越、倒影、波纹、投影或越界 → 保留暖白纸呼吸 → 让文案对齐透视与颜料边缘。

## 硬性视觉要求

- 从剪影、比例、轴线、朝向、开口、结构、动作、材质、落点或关系中保留至少三个源图专属线索。
- 建立一个精致等距微缩实体，具有清晰体积、稳定接触、前后关系、雕塑结构与统一斜向轴线；不得是平面插画或通用玩具模型。
- 从源图内容提炼一个主题厚涂色域，让它成为水面、地面、道路、草地、光带、岸线、影子或其他有依据的空间切片，而不是矩形或装饰色卡。
- 微缩主体必须真实落地、嵌入、穿越、延伸、倒影、制造波纹、投影或越过颜料边缘；刮刀脊、堆积颜料、起伏边缘与手工笔触连接二维色域和三维主体。
- 使用源图最明亮有神的颜色，提高生命力与纯净度，配大量清洁暖白和一处阳光点色；拒绝灰脏、莫兰迪钝化、荧光和廉价糖果色。
- 只保留一个视觉中心、斜向纵深、稳定重心、源图方向性位置和大面积留白；云、太阳、植物、波纹等只能低权重存在。

## 文案与语言

服从已经确认的自动文案、准确自定义文案或无文字模式，以及目标语言／地区。使用一个简短主体、地点、情绪或象征标题，只配必要副文、用户提供编号或微注释；目标语言文字沿等距方向、厚涂边缘、透视路径或暖白留白排列，必须呼应空间而不是悬浮成独立标题。 用户准确文案逐字保留；无文字模式不得出现字母、字符、数字、标题、标签或伪文字。

## 模式与验收


拒绝：平面贴图、矩形色块、主体与颜料无接触、塑料CG、玩具模型展示、通用微景观、灰脏或莫兰迪色、荧光或糖果色、过多次要场景、无依据悬浮与模板微景观。同时拒绝 logo、水印、色卡、UI、设备样机、无依据事实、伪外语和不可读文案。

任何硬性条件失败都必须纠正位图资产，不得以程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
